Example of other forms of loops - for extra credit. Written in C cuz why not

The loop you saw above was a "for" loop. uses a counting variable to track
how long the code has run for and when it should stop. it consists of three
sections: a starting value, a condition, and a description of how the variable should
change each time it loops.

Now about the other important loop, the "while" loop...

This is a loop that is to be used when you actually DON'T know how many times a
excerpt of code should execute.
Like, for example, keep doing an activity until it is done, not until you reach a
pre-determined stopping point with a for loop.
-------------------------------------------------------------------- 
    // basic while loop in C:
    
    #include <stdio.h>
    
    int main() 
    {
        int i = 0

        while (i < 5) {
            printf("%d\n", i);
            i++;
        }
        return 0;
    }
-------------------------------------------------------------------- 
    // output:
        0
        1
        2
        3
        4
--------------------------------------------------------------------
This while loop is set to keep outputting the same variable increasing until a condition is met. Here is a more practical example of the code, in a countdown sequence, that uses
BOTH liables:
--------------------------------------------------------------------
    // countdown
    #include <stdio.h>
    #include <time.h>

    int main(void) 
    {
        int seconds = 0;
        
        printf("Seconds: ");
        scanf("%d", &seconds);

        while (seconds > 0)
        {
            // output in format hh:mm:ss

            int h = seconds / 3600;
            int m = (seconds % 3600) / 60;
            int s = seconds % 60

            printf("\r%02d:%02d:%02d", h, m, s);

            // the call to printf() won't output newline so the stdout won't
            // flush the buffer causing time to output. have to flush manually.
            fflush(stdout);
        
            clock_t stop = clock() + CLOCKS_PER_SEC;

            while (clock() < stop) { }
            // empty loop causes program to pause for a second due to clock() returning the 
            // number of clock tics == to the expected number 1s into future.
         
            seconds--;
        }
        printf("\rEnd Timer.\n");

        return 0;
    }

And then after that, we have a significantly more powerful type of loop called a
Nested Loop, or in laymans terms, a loop in a loop.

If we combine all the loops we've learned up to this point, we can combine a for loop with a
while loop and get this abomination:
--------------------------------------------------------------------
#include <stdio.h>

int main()
{
    int i = 1;
    while (i <= 2)
    {
        // outer while loop
        for (int j = 1; j <= 2; j++)
        {
            // inner for loop
            printf("i = %d, j = %d\n", i, j);
        }
        i++;
    }
    return 0;
}
--------------------------------------------------------------------
It's important to know that there are many types of nested loops. The nested loop above is called a hybrid loop, simply because it contains a for loop and a while loop. That means that there are other nested loops called
  • Nested "for" loops;
  • Nested "while" loops;
  • Nested "do-while" loops; and of course
  • Nested hybrid loops
