CSS reference

External stylesheets, in-document <style> blocks, and inline styles all contribute to the final look of a page. Inline styles usually win, with important exceptions for !important and specificity.

Applying CSS

This paragraph starts green because of a class rule.

Current color: class rule.

.cascade-demo {
    color: #1f6f43;
}

/* Inline styles normally override this class rule. */
element.style {
    color: #b1005a;
}

Text formatting tags

Bold, strong, italic, emphasis, underline, marked, and code text all have different purposes. Choose the tag that matches the meaning, not only the appearance. 

<p>
    <b>Bold</b> and <i>italic</i> text
</p>

The box model

Margin, border, padding, and content all affect the space an element uses. 
.box-model-demo {
    margin: 1rem auto;
    padding: 1rem;
    border: 0.25rem solid #1f3864;
    box-sizing: border-box;
}

CSS refresher

  • Cascade order: external stylesheet, then in-document style, then inline style.
  • More specific selectors usually win over less specific ones.
  • Use rem for scalable spacing and px for precise borders.
  • Use box-sizing: border-box to make width calculations predictable.
  • Respect prefers-reduced-motion when adding transitions.
