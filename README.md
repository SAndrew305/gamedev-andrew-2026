# gamedev 2026

A collection of static HTML, CSS, and JavaScript pages created for a Game Development (Computer Programming) course I'm taking. The site is organised as a portfolio index plus one page per assignment or extra work.

## Development

Optional tooling is provided for consistent formatting and HTML validation.

- Tool configuration lives in `config/`.
- Root-level files such as `.config`, `.gitignore`, and `package.json` remain at the repository root because tools and editors expect them there.
- Install dependencies with `npm install`.
- Format the repository with `npm run format`.
- Check formatting and HTML with `npm run check`.

## Notes

- `t1a...` pages: term 1 assignments, named by subject matter (`table`, `list`, `forms`, ...).
- `t2a..` pages: term 2 assignments, named by subject matter (`table`, `list`, `forms`, ...).
- `x1a...` pages: additional works made during the first term made either with the intent of obtaining additional marks or just because I wanted to make something.
- `x2a...` pages: additional works made during the second term made either with the intent of obtaining additional marks or as a personal project.
- `baseline.css`: shared stylesheet; some older pages may carry their own inline styles
- `script.js`: dark mode toggle on all webpages.
